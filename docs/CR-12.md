## 2. สวิตช์ภาษา

### 2.1 ตำแหน่ง · หน้าตา

```
[≡] [ค้นหาหรือไปที่…  Ctrl+K]  DEV  ……………  [● Ploy · Brand ▾]  [ไทย│EN]  [☀│☾│🖥]
```

- **segmented control 2 ปุ่ม** ขวาของ Acting as · ก่อนปุ่มธีม · แบบ segment ของ KOL (ปุ่มที่เลือก = พื้นทึบ)
- ชื่อภาษา **เขียนด้วยภาษาของตัวเองเสมอ** (`ไทย` · `EN`) ไม่แปลตามโหมด — คนที่อ่านภาษาปัจจุบันไม่ออกก็หาเจอ
- tooltip / aria-label: `ภาษา · Language` (สองภาษาเสมอ) · `role="radiogroup"` + `aria-checked` · ←/→ เปลี่ยน · Enter / Space เลือก
- **Ctrl+K:** action `Switch to English` (ตอนเป็นไทย) / `เปลี่ยนเป็นภาษาไทย` (ตอนเป็น EN) · ป้ายขวา = `การแสดงผล` / `Display`
- **< 640 px:** ภาษา + ธีม รวมเป็นปุ่มไอคอนเดียว `การแสดงผล` → popover 2 แถว (ภาษา: `ไทย│EN` · ธีม: `☀│☾│🖥`)

### 2.2 การทำงาน

- **ค่าเริ่มต้น `th`** (เบราว์เซอร์ที่ยังไม่เคยเลือก) · จำใน pref `lang` (`charmiss_campaign_pnl_lang`)
- URL **`?lang=th|en`** บังคับภาษาสำหรับการโหลดครั้งนั้น (ใช้ทดสอบ / ถ่ายภาพ) — **ไม่บันทึก** เป็นค่าจำ
- **สลับ = บันทึกค่า แล้วโหลดหน้าเดิมใหม่** (hash route · แท็บที่เปิด · ตำแหน่ง scroll คืนเหมือนเดิม — scroll เก็บใน sessionStorage ใช้ครั้งเดียว)
  - เหตุผล: ทุก screen ถือ `C` ไว้ตั้งแต่โหลด (`const C = CP.content, D = C.dash …`) → reload ปลอดภัยที่สุด ไม่ต้องรื้อ screen
  - มีฟอร์ม / ตารางที่ยังไม่บันทึก → ถามด้วย dialog เดิม `Discard changes?` / `ทิ้งการแก้ไข?` ก่อน · กด "แก้ไขต่อ" = ไม่สลับ
- `<html lang="th|en">` · `<title>` ตามภาษา
- ค่าอื่นที่จำไว้ (Acting as · ตัวกรอง · แถวที่เปิด · แท็บ · ธีม) อยู่ครบหลังสลับ
- **ไม่แปลข้อมูล** — ดู §5.3

## 3. ธีม Light · Dark · System (James เพิ่ม)

- ปุ่มเดิม `themeBtn` (กดสลับ 2 แบบ) → **segmented 3 ปุ่มไอคอน** `☀ สว่าง │ ☾ มืด │ 🖥 ตามระบบ` (ไอคอน sun / moon เดิมใน `icons.js` + เพิ่ม `system` = รูปจอ — **ไม่ใช้** ไอคอน `monitor` ของเมนู)
- tooltip ปุ่มละคำ · ปุ่มตามระบบ: `ตามระบบ (ตอนนี้: มืด)` / `System (now: Dark)` · ⓘ ของกลุ่ม = `app.theme.tip`
- **ค่าเริ่มต้น `system`** สำหรับเบราว์เซอร์ใหม่ · pref `theme` เดิม (`light` / `dark`) ใช้ต่อ · URL `?theme=light|dark|system` บังคับครั้งนั้น ไม่บันทึก
- **ตามระบบ** = `matchMedia('(prefers-color-scheme: dark)')` + ฟัง `change` → เปลี่ยนธีมทันที + วาดกราฟใหม่ (ทางเดียวกับการกดปุ่มตอนนี้ `showPage(current)`)
- CSS ไม่ต้องแก้: `data-theme` ยังเป็น `light` | `dark` (ค่าที่ resolve แล้ว) · เพิ่ม `data-theme-pref="light|dark|system"` ไว้ให้ปุ่มรู้สถานะ
- **ไม่มีจอขาวแวบ:** ตั้งธีม + ภาษาใน `<head>` ก่อนวาดหน้า (`src/boot.js` §4.1)
- Ctrl+K: `ธีม: สว่าง` · `ธีม: มืด` · `ธีม: ตามระบบ` (`app.theme.cmd`)
- Export ไม่เกี่ยวกับธีม

### 4.1 ไฟล์ · ลำดับโหลด

| ไฟล์ | หน้าที่ |

| `src/content.th.js` **มีแล้ว** — ต่อจาก `content.js` | `CP.contentTH` โครงเดียวกับ `CP.content` (ชื่อ key เดิม · array ตามลำดับเดิม) |
| `src/i18n.js` **ใหม่** — ต่อจาก `content.th.js` | ถ้า `CP.lang === 'th'` → merge `CP.contentTH` ลง `CP.content` **ในที่เดิม (in place)** ก่อน screen ใดโหลด · `CP.i18n = { lang, set(lang), check() }` |

ลำดับใน `index.html`: `styles.css` · **`boot.js`** (head) … `mock-scenario.js` · `content.js` · **`content.th.js`** · **`i18n.js`** · `icons.js` · … (ที่เหลือเหมือนเดิม)

**กติกา merge**
- object → merge ทีละ key · **array → ทีละ index** (item ที่เป็น object merge ต่อ · string แทนที่) — `nav` / `cmdk.pages` ฯลฯ ใน TH มีแค่ `label` / `right` · `key` `route` `icon` `hash` คงของ EN
- string / function → แทนที่เมื่อ **ชนิดเดียวกัน** เท่านั้น · function ต้องรับ argument เท่ากัน (`fn.length`) — ไม่ตรง = ข้าม + แจ้งใน check
- key ที่มีจุดในชื่อ (`'request.approved'` · `'price.MT'`) = key ธรรมดา ไม่ใช่ path
- key ที่ไม่มีใน EN → ไม่ใช้ + แจ้งใน check · **ไม่มีใน TH → ใช้ EN (fallback)** — หน้าไม่พัง

### 4.2 ตัวตรวจ `?i18n=check` (dev)

หลัง render แต่ละหน้า แสดงแผงเล็กมุมจอ + `console.table`:
- **(a)** key ใน `content.js` ที่ต้องแปลแต่ไม่มีใน TH — "ต้องแปล" = มีตัวอักษรละติน · ไม่อยู่ใน keep-list §5.2 · ไม่ใช่ field `key` `icon` `route` `hash` `version`
- **(b)** key ใน TH ที่ไม่มีใน EN (พิมพ์ผิด / key ถูกลบ) · **(c)** function รับ argument ไม่เท่ากัน
- **(d)** ไล่ DOM ที่มองเห็น + `title` · `aria-label` · `placeholder`: คำอังกฤษ ≥ 3 ตัวอักษร ที่ไม่อยู่ใน keep-list และไม่ใช่ข้อมูล (ชื่อ Campaign · สินค้า · SKU · ช่องทางย่อย · รายการงบ · คน จาก Mock) → รายการ + selector
- `ops` (แท็บ Operations เดิม — ไม่มีไฟล์ไหนใช้แล้ว) **ยกเว้นจาก (a)** · ยืนยันว่าไม่ได้ใช้จริงในรายงาน

## C. สิ่งที่ Claude ตัดสินใจเอง (นอก §9)

1. **dialog ตอนสลับภาษาที่ยังมีของไม่บันทึก:** ใช้ dialog เดิมของ CR-05 (*Leave without saving?* / *ออกโดยไม่บันทึก?* · ปุ่ม Stay / Leave) ไม่สร้าง *Discard changes?* ใหม่ — spec สั่ง "dialog เดิม" · drawer ที่ยังไม่บันทึกก็ถามแบบเดิมเช่นกัน
2. **ⓘ ของกลุ่มธีม:** ตามกติกา CR-08 (ⓘ เฉพาะเลขที่มีสูตร) คำอธิบาย `app.theme.tip` จึงเป็น tooltip ของปุ่ม *ตามระบบ* และของหัวแถว *ธีม* ใน popover (ไม่ใช่ปุ่ม ⓘ)
3. **check (d) "ข้อมูล":**
   - ทุกคำที่อยู่ในข้อมูลเดโมนับเป็นข้อมูล (ชื่อแคมเปญ · สินค้า · SKU · ช่องทางย่อย · รายการงบ · คน · เหตุผล / ความเห็นใน plans)
   - ค่า enum ตัวเล็ก (`approved` · `marketing`) ไม่นับ
4. **keep-list เพิ่มจาก §5.2:**
   - ชื่อแบรนด์ / แอป: Campaign P&L · Charmiss · LOMR
   - คำที่เหลือ: Est. · pcs · xlsx / Excel · Windows / macOS · Mock · รูปแบบวันที่ `mm/yyyy` · `pace` ตัวเล็ก (ไฟล์แปลใช้ใน "pace ปัจจุบัน")
   - คำในสวิตช์ภาษาที่ตั้งใจเป็นสองภาษา: "Language" · "Switch to English"
5. **ชื่อขั้นใน log:**
   - log ของ Mock สร้างใหม่ทุกครั้งที่เปิดหน้า → ใช้ภาษาของหน้าตอนนั้น
   - log ที่เกิดจากการคลิกจะบันทึกเป็นภาษาที่ใช้อยู่ตอนนั้น และไม่แปลย้อนหลัง (เป็นข้อมูล)
6. **คำในไฟล์ Export ที่เขียนไว้ในโค้ด** → กลุ่มใหม่ `C.xl` (53 key · EN + TH)
