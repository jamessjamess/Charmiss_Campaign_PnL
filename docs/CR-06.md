## 5. Campaigns › Timeline (Gantt)

**แท็บ:** `Table · Timeline · Approvals (n)` (แบบ KOL Campaign & Phase) · route `#campaigns/timeline` · จำแท็บล่าสุด

- **ใช้ toolbar และ status tabs ชุดเดียวกับ Table** (Year · Search · Include cancelled · All / On going / Not started / Complete / Draft / Pending approval …) · Sort ของ Timeline = **Start date** (ตั้งต้น) · Status · Name
- หัวการ์ดขวา: seg **Month | Quarter** (ความกว้างคอลัมน์) · seg Group **None | Owner | Approval** · ปุ่ม Export (1 sheet: Campaign · Approval · Status · Start · End marketing · End · Owner · Starts in / Days left)
- **แกน:** Year ที่เลือก = ม.ค.–ธ.ค. · *All years* = เดือนแรกของ Start แรกสุด → เดือนสุดท้ายของ End ท้ายสุด · ชื่อเดือนแบบ `Jan` + ปีใต้เดือนแรกและเมื่อปีเปลี่ยน (CR-01 §2.4) · เดือนปัจจุบันตัวหนา · เส้น **Today** แดงประ + ป้าย · เลื่อนแนวนอนในการ์ด (คอลัมน์ชื่อ + คอลัมน์สรุป sticky) · เปิดมาเลื่อนให้ Today อยู่กลางจอ
- **แถบกิจกรรมด้านบน:** แถวเล็ก *Running* = จำนวน Campaign ที่ Approved และวิ่งอยู่ในเดือนนั้น (ตัวเลข + แท่งเทาสั้น) — เห็นว่าเดือนไหนชนกันเยอะ
- **แถว = Campaign:** ชื่อตัวหนา + avatar ตัวอักษร Owner · chip เมื่อไม่ใช่ Approved (`Draft` · `Pending approval` · `Returned`)
  - แท่ง Start → End marketing (ทึบ) · End marketing → End campaign (เส้นบาง) — ชิ้น gantt เดียวกับ Overview (`ganttAxis` · `.gbar`)
  - สี: Approved ตามสถานะเวลา (Not started `--st-ns` · On going `--g-prog` · Complete `--ok`) · **Draft** = กรอบประเทา · **Pending approval** = ลาย hatch warn · **Returned** = กรอบ warn · **Cancelled** = เทาลาย (เฉพาะติ๊ก Include cancelled) · Rejected ไม่แสดง (ยกเว้นเลือก tab Rejected)
  - ป้ายวันที่เริ่ม `01/03` ที่หัวแท่ง · แท่งที่เริ่มก่อนแกน = `◀ 15/10/2025`
  - **คอลัมน์สรุปขวา:** `Starts in 58 days` · `57 days left` · `Ended 30/09/2026` · `Draft · starts 01/04/2027` · `Cancelled 20/07/2026`
- Tooltip: ชื่อ · Approval · Status · Start – End · End marketing · Owner · Target · Budget · คลิกแถว / แท่ง → หน้า Campaign · คีย์บอร์ด ↑ ↓ Enter
- 390 px: การ์ดเลื่อนแนวนอน · ชื่อ sticky
- Overview › *Campaign timeline* ของ Dashboard **คงไว้** (เฉพาะ Approved + ยอดขายรายเดือนบนแท่ง — ดูผล) · Campaigns › Timeline = วางแผน (ทุกสถานะ · ไม่มียอดขาย) (D56)
