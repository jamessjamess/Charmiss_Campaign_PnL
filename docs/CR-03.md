## 4. Status (D25)

ลำดับการตัดสิน: **Cancelled** → เลย End campaign = **Complete** (D5) → status = `Complete` (ปิดก่อนกำหนด) → วันนี้ก่อน Start = **Not started** → **On going**

- On going / Not started **คิดจากวันที่ทุกครั้ง** (ไม่ต้องแก้มือเมื่อถึงวัน Start) · ตอน save เขียนค่าที่คิดได้ลง CSV เพื่อให้อ่านใน Excel รู้เรื่อง
- `R.STATUSES` คงเป็น 3 ค่าเดิม (= "All" ของ dropdown Status) · Cancelled แยกเป็น `R.CANCELLED` + option `includeCancelled` ใน `scope()` → default ไม่รวม → anchor ไม่เปลี่ยน · `statusOf()` คืน `'cancelled'` ได้
- scope Campaign เดียว (By campaign · Waterfall Scope = 1 Campaign) อ่าน Campaign ที่ Cancelled ได้เสมอ
- 7 Campaign เดิมต้องได้ status เท่าเดิมที่ today = 04/11/2026 (TC08)

## 6. Store — `src/store.js` (`CP.store`) · ที่เดียวที่เขียนไฟล์

### 6.1 โฟลเดอร์ 2 ที่

| key | โฟลเดอร์ | ตรวจว่าเลือกถูก |
|---|---|---|
| `project` | `Campaign PnL - Web Dev` | มี `index.html` และ `data/campaigns.csv` |
| `pnl` | `Available Campaign` | มีไฟล์ใน list อย่างน้อย 1 ไฟล์ หรือชื่อโฟลเดอร์ = ท้ายของ `meta.source_folder` · ใช้เฉพาะ *Create from template* / *Use a file already in the folder* |

- `showDirectoryPicker({ id, mode: 'readwrite' })` · เก็บ handle ใน IndexedDB `charmiss_campaign_pnl` › `handles` (เก็บไม่ได้ → จำในหน้าเท่านั้น เลือกใหม่ทุกครั้งที่เปิด)
- **เปิดหน้าไม่ถามอะไร** · ขอสิทธิ์ (`requestPermission`) ตอนกด Save เท่านั้น (ต้องมี user gesture)
- เลือกผิดโฟลเดอร์ → ข้อความบอกชื่อโฟลเดอร์ที่ต้องเลือก · ไม่เก็บ handle
- ใช้ทดสอบ: `CP.store._use(key, handle)` ฉีด handle เข้าได้ (เช่น OPFS `navigator.storage.getDirectory()` บนสำเนาไฟล์) — headless คลิก picker ไม่ได้

### 6.2 Save (Add · Edit · Cancel · Restore) — ลำดับ

1. อ่าน `campaigns.csv` **จากดิสก์** (ไม่ใช่จาก `campaigns.js`) แล้วใส่การเปลี่ยนแปลงบนฉบับนั้น — แถวที่มีคนแก้มือไว้ไม่หาย · ถ้าต่างจากที่หน้าเว็บมี → toast *The list changed on disk — reloaded*
2. `validateCampaign` อีกรอบกับฉบับดิสก์
3. (Add + *Create from template*) คัดลอก Template → โฟลเดอร์ `pnl` · ล้ม → หยุด ไม่เขียน list
4. เขียน `campaigns.csv` → `campaigns.js` → ต่อท้าย log (`createWritable()` เขียนทั้งไฟล์ครั้งเดียวแล้ว `close()`)
5. ล้มหลังข้อ 3 → toast บอกชื่อไฟล์ P&L ที่สร้างไปแล้ว (ไม่ลบเอง)
6. อัปเดต `CP_LIST` ในหน้า → render ใหม่ทุกหน้า · toast ผลลัพธ์ (§8)

### 6.3 ไฟล์ในโฟลเดอร์ P&L

`listPnlFiles()` = `.xlsx` ในโฟลเดอร์ `pnl` ที่ยังไม่มีใน list (ไม่นับ `~$…`) → ตัวเลือก *Use a file already in the folder* · ยังไม่มีสิทธิ์ `pnl` → ใช้ `meta.ignored_files` ของ seed แทน (บอกว่าเป็นรายชื่อ ณ build ล่าสุด)

### 6.4 แถบ stale

`listStale()` → แถบเตือนบนหน้า Campaigns (§7) · หายเมื่อรัน `build_seed.py` แล้ว reload

### 6.5 Fallback — Download

ไม่มี `showDirectoryPicker` · กดยกเลิก picker · สิทธิ์ถูกปฏิเสธ · หรือ R3 พบว่า `file://` ใช้ไม่ได้ →
- ดาวน์โหลด `campaigns.csv` + `campaigns.js` (ชื่อเดิม · ใช้ `U.download`) · toast *Saved as downloads — put both files in data\ and reload*
- *Create from template* ใช้ไม่ได้ในทางนี้ (ปิด + tooltip) · log ไม่บันทึก · หน้าเว็บแสดงผลทันทีในรอบนั้น
