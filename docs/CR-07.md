## 3. นิยามใหม่ (ใช้ทุกที่ · pure function ใน `rules-pnl.js`)

### 3.1 Time gone และ Sales pace (R4)

| ค่า | สูตร |
|---|---|
| **Time gone %** | (วันนี้ − Start + 1) ÷ (End − Start + 1) · 0–100% · ยังไม่เริ่ม = 0 · จบแล้ว = 100 |
| **Ach %** (บน Dashboard / Monitor) | Actual to date ÷ **Full target** ของ Campaign |
| **Pace** | Ach % ÷ Time gone % (ตัวอย่าง Ach 76% · Time gone 91% → Pace 0.84) |
| **Sales status** | **On track** Pace ≥ 0.95 · **At risk** 0.85–0.95 · **Behind** < 0.85 · ยังไม่เริ่ม / Time gone < 10% = "—" (เร็วไปที่จะบอก) |
| Ach to date (แบบเดิม — เทียบ target ของเดือนที่ผ่านมา) | คงไว้เป็น tooltip และในตาราง Monitor › Sales เท่านั้น |

- ระดับปี (Overview): Time gone ของปี = วันนี้ ÷ วันของปี · Ach ของปี = Actual YTD ÷ Full-year target (Campaign ที่ Approved ในปีนั้น)
- กราฟ / ตารางที่เทียบสองค่านี้: แท่ง = Ach % · ขีดดำ = Time gone % · ตัวเลข `Ach 76% · Time 91% · −15 pts`

### 3.2 Budget health

| ค่า | สูตร |
|---|---|
| **Used %** | Spent ÷ Current budget (งบที่อนุมัติ + คำขอเพิ่มที่อนุมัติ) |
| **Budget status** | **Over budget** Used > 100% · **Near budget** 90–100% และ Campaign ยังไม่จบ · **Spending ahead** Used % − Time gone % > 20 pts · ที่เหลือ OK · Campaign ที่จบแล้วและเกินงบ = **Ended over budget** (watch — ยังอยู่ใน Watchlist ของปีนั้น) |

### 3.3 Issues — กติกาเดียว (R2 · R3)

`R.issues(seed, o)` → `[{ id, severity, chips: [...] }]` 1 รายการต่อ Campaign · severity **urgent** (Behind · Over budget) / **watch** (At risk · Near budget · Spending ahead) · ใช้ทั้ง KPI Campaigns · Watchlist · Monitor · Planning › Plans (chip) — ตัวเลขต้องตรงกันทุกที่

## 8. ขั้นที่ 5 — Forecast P&L ("ด้วยงบนี้ จบ Campaign จะได้ P&L เท่าไร")

| Gross profit · GP % | | | | |
| Marketing · Sales · Other exp | งบ (คงที่) | | | |
